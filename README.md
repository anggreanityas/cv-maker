# CV Maker

Website pembuat CV profesional: isi data sekali, pilih dari 46 template, lalu unduh sebagai PDF atau JPG.

## Fitur
- 46 template (Premium, Klasik, Modern, Elegan, Interaktif, Clean) dan 40+ pilihan warna, termasuk warna sendiri
- Pratinjau langsung ukuran A4
- PDF rapi per halaman (tanpa baris terpotong, tautan bisa diklik) dan JPG satu gambar utuh
- Isian tersimpan otomatis di peramban perangkat pengguna
- Responsif untuk laptop, tablet, dan HP

Fitur berbasis Claude (isi otomatis dari profil, terjemahan, dan bantuan menulis) hanya aktif saat dibuka sebagai artefak di claude.ai. Di GitHub Pages, fitur tersebut otomatis disembunyikan.

## Menjalankan
Cukup buka `index.html` di peramban. Tidak ada proses build.

## Deploy ke GitHub Pages
1. Unggah `index.html`, `README.md`, dan `.nojekyll` ke repository.
2. Buka **Settings → Pages**.
3. Pada **Source**, pilih **Deploy from a branch**, lalu branch `main` dan folder `/ (root)`. Simpan.
4. Tunggu 1–2 menit. Website tersedia di `https://<username>.github.io/<nama-repo>/`.
